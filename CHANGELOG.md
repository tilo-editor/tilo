# Changelog

## Unreleased

- No unreleased public changes.

## v0.5.0 - 2026-06-05

- Added inline blame for the current line (`Alt+B`).
- Added a branch picker for switching local branches from the TUI.
- Added hunk-level stage (`Alt+S`) and undoable in-buffer hunk revert.
- Expanded the Git ribbon and command palette coverage.
- Added the public Tilo guide and updated user docs for source control,
  formatting, highlighting, and preview constraints.

## v0.4.0 - 2026-06-04

- Added Format Document for Go, JSON, YAML, TOML, and XML.
- Added optional Taplo install for deep TOML formatting.
- Added Chroma-backed highlighting for JSON, TOML, YAML, and XML.
- Added example files for formatter/highlighter smoke testing.
- Added a dependency ledger documenting compiled and external dependencies.

## v0.3.1 - 2026-06-02

- Synced the settings UI with the full config surface.
- Added settings rows for palette lists, keybindings, wheel step, completion
  prefix length, reload config, and reset defaults.

## v0.3.0 - 2026-06-02

- Added manual update checks with optional weekly passive notices.

## v0.2.2 - 2026-06-02

- Exposed two-column view in help and public docs.

## v0.1.0

Initial preview release.
